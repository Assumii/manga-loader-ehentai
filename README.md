# Manga Loader (E-Hentai / ExHentai 复活版)

一个轻量、零外部依赖的 **E-Hentai / ExHentai 瀑布流连续阅读** 油猴用户脚本（Userscript）。

灵感源于经典脚本 [fuzetsu/manga-loader](https://github.com/fuzetsu/manga-loader)，因原版早已移除 NSFW 站点且长期停止维护，本项目对其核心架构进行了现代化重构，并针对当前线上的 E-Hentai / ExHentai 页面结构、H@H 节点特性与防风控机制做了深度适配。

---

## 核心特性

- **双站全适配**：同时支持 `e-hentai.org` 与 `exhentai.org` 的单页阅读页（`/s/*/*`）和画廊详情页（`/g/*/*`）。
- **画廊一键开看**：在画廊详情页右侧操作栏与右下角注入「瀑布流阅读」快捷入口，一键进入连续阅读模式（也可在单页按 `Ctrl + ,` 启动，或开启自动进入）。
- **滑动窗口智能预加载（默认 `40P` 初始 / 剩 `10P` 续载 `20P`）**：
  - 打开后自动后台预加载前 `40` 页；
  - 当阅读到前方剩余未看页数 **≤ `10` 页** 时（例如读到第 `30` 页），自动追加预加载下一批 `20` 页；
  - 首次页数、每次续载页数、剩余触发阈值与请求间隔（默认 `300ms`）均可在设置面板自由定制。
- **随滚动方向自动显隐的悬浮顶栏**：
  - 向下滑动/滚轮下滚时自动向上隐藏，全屏沉浸阅读；
  - 向上滑动/滚轮上滚时立即向下滑出，随时查看标题、返回画廊、退出到当前页或切换显示模式。
- **E-Hentai 专属「真 `nl` 换源重载」**：
  - 图片加载失败时，自动解析并链式调用 `?nl=...` 向 E-Hentai 申请更换新的 H@H 节点重试（默认最多自动重试 2 次）；
  - 支持点击每页下方的「换源」按钮、按 `R` 键刷新当前屏图片，或开启右下角刷新模式点击任意图片换源。
- **配额与防风控保护**：
  - 串行节流预加载 + HTTP `503/429/502/504` 自动退避重试；
  - 自动检测 `509.gif` / `509s.gif` 配额耗尽与站点限流提示，触发后立即暂停并提醒，保护账号与 IP。
- **多种阅读显示模式 & 无级缩放**：
  - 支持 **智能适配 / 适应宽度 / 适应屏高 / 原始尺寸** 一键切换，以及 `+` / `-` / `0` 百分比缩放；
  - 切换模式或缩放时自动锁定当前视觉锚点，阅读位置不跳动。
- **高度可定制**：
  - 完整保留 **多套自定义 CSS 配置方案（CSS Profiles）**，内置「纯黑无缝条漫」预设；
  - 全部快捷键支持按键录入自定义；
  - 纯内联 SVG 图标，无任何外部 CDN 依赖。

## 安装方式

### 方式一：通过 GitHub Raw 链接一键安装（推荐）

1. 在浏览器中安装脚本管理器扩展：[Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 或 [Violentmonkey（暴力猴）](https://violentmonkey.github.io/)。
2. 点击下方链接，油猴会自动弹出安装页面，点击**安装**即可（后续在仓库升级 `@version` 后，油猴也支持自动检测更新）：

> 👉 **[点击一键安装 Manga Loader (E-Hentai / ExHentai 复活版)](https://raw.githubusercontent.com/Assumii/manga-loader-ehentai/main/manga-loader-ehentai.user.js)**

### 方式二：手动复制安装

1. 打开仓库中的 [`manga-loader-ehentai.user.js`](./manga-loader-ehentai.user.js) 文件，复制全部代码。
2. 点击浏览器油猴图标 → **添加新脚本** → 清空默认模板后粘贴保存（`Ctrl + S`）。

## 使用方法与快捷键

### 启动入口

- **画廊详情页（`/g/...`）**：点击右侧栏或右下角的「**瀑布流阅读**」按钮，或按 `Ctrl + ,`。
- **单页阅读页（`/s/...`）**：点击右下角「**瀑布流阅读 (Load Manga)**」按钮，或按 `Ctrl + ,`。
- 如希望以后点开任意图片页直接自动进入瀑布流，可在右下角齿轮（设置）中勾选 **「打开单页图 (`/s/`) 时自动进入瀑布流」**。

### 默认快捷键（均可在设置中自定义）

| 快捷键 | 功能 |
| :--- | :--- |
| `Ctrl + ,` | 在画廊页或单页快速启动瀑布流阅读 |
| `W` / `S` | 向上 / 向下滚动 |
| `←` / `→` | 跳到上一页 / 下一页图片 |
| `+` / `-` / `0` | 放大 / 缩小 / 重置缩放 |
| `R` | 使用 `nl` 换源刷新当前屏幕正在看的这一页 |
| `X` | 退出瀑布流（精准回到当前正在看的单页，不被自动加载拉回） |
| `G` | 返回画廊详情页 |
| `Esc` | 关闭悬浮设置/帮助面板或退出手动换源模式 |

## 配置与自定义 CSS

点击右下角悬浮状态栏的 **齿轮图标** 可打开设置面板：

- **滑动窗口预加载**：自定义首次预加载页数（支持填 `all`）、每次续载页数、剩余多少页时触发续载。
- **请求节流间隔**：默认 `300ms`，网络较敏感或高并发场景可调大（如 `500ms` ~ `1000ms`）。
- **显示选项**：开关底部页码/原图/换源条、开关失败自动 `nl` 换源重试、调整图片间距与默认显示模式。
- **自定义 CSS Profiles**：支持新建和切换多套样式方案，实时生效。常用类名参考：
  - `.ml-images`：图片流主容器
  - `.ml-page-wrap`：单页包裹容器
  - `.ml-page-img`：漫画图片元素
  - `.ml-page-bar`：每张图下方的页码/信息/换源条
  - `.ml-nav-top`：顶部随滚动自动显隐的导航栏
